3. The §7 category needs P-P2b, which the plan's S8 order computes after the aggregates; the category is therefore written by `forecast_pyt.py` (section K), not by the aggregates.
4. V-P9's end-to-end run "through E, I, R and `forecast_pyt.py` with 0 mismatches" and V-P8 need the E, I and R code; this role supplies the stand-in Part B (`partb_pyt.py --standin vp9`), the fixture layout (spec §13) and the comparator, and ran `forecast_pyt.py` end to end on the stand-in (E- and I-format pair files, 0 FK mismatches) with hand-made aggregate inputs.
