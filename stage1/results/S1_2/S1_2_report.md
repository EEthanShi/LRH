## 8. Deviations and limitations

1. **Power-gate pool.** The PREREG specifies m = 3072; the fallback pool here is m = 2047, for the reasons in §3. S_sel rows enter only that fallback evaluation (PE2) and the PE3 PCA fits. No layer or estimator choice was made on S_sel in S1.2.
2. **D6.** The PREREG does not say whose 1-NN forest is meant.
   - The SPEC-literal reading, with A = LM, was fixed as primary before the run.
   - The B, union and intersection readings are reported as sensitivities, with unadjusted p.
3. **Layer rule.** The rule follows the task specification (§2). It differs from the extraction-sidecar rule for ViTs at r = 0.5 (§7).
4. **Not run.**
   - ARH layer-max, a secondary replication item.
   - The SPEC §4 GL criterion, which is for linear models only.
5. **Both depths are primary in the PREREG,** so each endpoint has two verdicts. The Holm family therefore has 4 tests.
6. **Bootstrap design.**
   - Pair-level fractions and medians use the two-way cluster bootstrap.
   - LM-size trends resample ViTs only.
   - Vision-side trends report exact p only.
7. **Duplicate captions.** WIT items 493 and 531 are kept, per the PREREG "no run is dropped". They create exact LM-side ties, which are resolved by the SPEC lower-index rule.
