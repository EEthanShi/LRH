# Stage 2 preregistration (v1.0, 2026-10-08) — S2.1 objective link, S2.2 gauge net

Frozen before any confirmatory (main) run is trained. Its sha256 is recorded in `prereg/PREREG_stage2.sha256` and in `~/hrh_v2_stage1_20261008/STATUS.md` (role `stage2`). Any later change needs a new version with a changelog entry. Pilot runs are EXCLUDED from every confirmatory count and are labelled `*-pilot`. No run is ever dropped.

Source of the design: `final_plan_en.md` §3 Stage 2 (S2.1, S2.2), `theory_learning.md` §4 (Lemma 6, co-occurrence), §5 (Theorem 4, objective link), §6 (GL obstruction). Metrics: `hrhv2` (Stage-1 harness, SPEC v1.0 + SPEC_CHANGELOG.md, imported read-only from `~/hrh_v2_stage1_20261008/hrhv2`).

## 0. Data (CIFAR-5m; no deviation from the plan)

- CIFAR-5m (Nakkiran et al. 2021), `storage.googleapis.com/gresearch/cifar5m/part{0..5}.npz`, md5-verified, memory-mapped in place.
- **Train pool** = parts 0–4 (5,002,240 images). Each run draws its own subset of size N uniformly without replacement, seeded by sha256 of its data key, so subsets are independent across runs and the design estimates the unconditional μ_r. Expected overlap between two runs is N/5.0M (1% at 50k, 10% at 500k); it is random, not designed.
- **Held-out** = part 5 only, ordered by sha256(`hrhv2-stage2|heldout|part5:<i>`):
  - **S** = first 2048 items: the evaluation set for every criterion (m = 2048). Never used in training.
  - **bank** = next 10,000 labelled items (kNN accuracy / test accuracy).
  - **hold** = next 4,096 items (held-out loss for the generalization-gap covariate).
- Shared-corpus cell (S2.2): one subset per corpus c, drawn from key `…|corpus=c|data`, reused by that corpus's runs.

## 1. Seeds

Key = `hrhv2-stage2|<exp>|arm=<arm>|N=<N>|rep=<r>[|corpus=<c>]`; purposes `|data`, `|init`, `|order`, `|aug`, `|evalsel`; seed = first 8 bytes (little endian) of sha256(key). Seed-deterministic; GPU kernels are not bitwise reproducible (cuDNN autotune, bf16). Run lists are fixed in `plans/*.json` (generated by `src/make_plan.py`), in rep-major order.

## 2. S2.1 — objective link (endpoint PE4)

### 2.1 Training
- Backbone: airbench94 trunk (2×2 whitening conv initialised from 5,000 unaugmented images of the run's own subset; ConvGroups 64/256/256; BN weight frozen at 1, BN momentum 0.6; GELU; global max-pool) → h ∈ ℝ²⁵⁶. Projector 256→512 (no bias) → BN → ReLU → 128 = z (critic space).
- Augmentation (GPU): RandomResizedCrop(32, scale (0.2,1), ratio (3/4,4/3)) + horizontal flip; ColorJitter(0.4,0.4,0.4,0.1) with p = 0.8 (fixed order b→c→s→h; hue = chroma rotation in YIQ); grayscale p = 0.2.
- Optimiser (all arms identical): SGD, Nesterov momentum 0.9, lr 0.5, weight decay 5e-4 on weights (not biases/BN), batch 512 images (1024 views), linear warm-up 2% then cosine to 0, bf16 autocast.
- **Fixed budget B = 5,000,000 images seen** (9,765 steps) at every N, so N varies at fixed B.
- Arms (single intervention = the objective's link):
  - **A**: InfoNCE (NT-Xent, 2B×2B), cosine critic, τ = 0.2.
  - **B**: spectral contrastive loss (HaoChen et al. 2021), −2E⟨f,f⁺⟩ + E_{x≠x'}⟨f,f'⟩², with HaoChen's official radial projection onto the ball ‖f‖ ≤ √μ, μ = 1. Evaluated with the cosine kernel (primary); raw inner product secondary.
  - **A_τ**: InfoNCE, τ = 0.5 (matched control; predicted pure scale relative to A).
- **N ∈ {50,000, 500,000}; 64 runs per (arm, N)** = 384 runs. Plus the plan's **fixed-epoch sensitivity cell**: arms A and B at N = 50k with 10 epochs (500k images seen), 32 runs each (exp `S2.1-fixedepoch`), reported descriptively only.
- Pre-pilot engineering (excluded, nothing saved): unconstrained spectral loss diverged at every lr tried (0.005–0.5); with μ = 1 it trains (raw ‖z‖ ≈ 8–16, so the projection is active for all samples: arm B is effectively the spectral loss on the unit sphere, and its raw norm is not trained by the loss — the raw-inner-product secondary is reported with that caveat). lr 0.5 was chosen once for all arms from 1,500-step runs (kNN on h 0.72–0.74 InfoNCE, 0.71 spectral).

### 2.2 Saved per run (on S)
z, h (eval-mode BN, fp32), z_init and h_init (at initialisation, BN batch statistics), kNN accuracy on h and z (k = 20, cosine, weights exp(s/0.07), bank → S), final train loss, eval-mode SSL loss on 4,096 own-train vs 4,096 hold images (gen gap), wall time, subset sha256.

### 2.3 Gate G2 (pilot; EXCLUDED; exp `S2.1-pilot`)
16 runs per arm at **N_pilot = 150,000** (a condition disjoint from the tested cells), same budget. Pass if all hold:
- mean kNN accuracy (h) ≥ 0.70 for every arm, and max − min of the arm means ≤ 0.05;
- within-arm mean s_N(k = 10) on z (pre = l2) ≥ 0.3 for every arm (8 disjoint pairs each);
- median wall time per run ≤ 300 s.
Evaluated automatically by `src/gates.py` as soon as the 48 pilot runs exist; it writes `runs/GATE_S2_1_main.go` or `.nogo`. Main runs are queued behind the gate. If G2 fails: fallback per plan (ResNet-18-small at one N = 500k), recorded as a deviation.

### 2.4 Representations, pairs, tolerances
- Primary: z with pre = `l2` (cosine kernel). Secondary: h (`l2`); z with pre = `none` (raw inner product).
- Disjoint pairs at each N: within-arm (rep 2j, 2j+1), j = 0…31 → 32 pairs per arm; cross A–B (A_i, B_i), i = 0…63 → 64 pairs; cross A–A_τ (A_i, A_τ,i) → 64; cross A_τ–B (secondary) → 64.
- Calibration arm (zero cost): Bernstein warp φ(K) = exp(β(K − 1)) of A's cosine Gram, β = 1/τ_A = 5: self pairs (A_i, φ(A_i)) (64; pure-link signature) and peer pairs (A_2j, φ(A_2j+1)) (32; predicted cross profile if B were an exact Bernstein link of A).
- **Full ladder** (`hrhv2.ladder`, SPEC v1.0) on every pair: T_N k ∈ {1,3,10,30,100,k_q}, T_C k ∈ {1,3,10}, Δ_O, Δ_E (exact), MST with forest/bridge split, Gs, raw G (same pre only), CKA biased/debiased, Pearson RSA, SOG kNN/MST τ ∈ {1,0.1,0.01,0.001,1e-4}, quotients (scale, affine, global isotonic, row isotonic; in-sample and cross-fitted, both directions), projector/CCA. Halves split by `hash_half` on the S item ids.
- Discrepancies Δ_Q: T_N(k): 1 − s_N(k); T_O: Δ_O; T_E: Δ_E; MST: 1 − s_T; Gs: Gs_rms; Aff: 1 − RSA; SOG-τ: 1 − sog_knn10_τ; CKA: 1 − CKA_biased; raw G: G_rms; **Iso**: Δ_iso = ½(iso_rms_cf(A→B)/ν_B + iso_rms_cf(B→A)/ν_A) (cross-fitted global-isotonic residual RMS in units of the target's mean distance ν); **warp share** ω = 1 − SS_iso,cf/SS_aff,cf (mean of both directions; the fraction of the affine residual removed by a monotone warp).
- **Tolerance rule** (frozen before any main ladder is computed): for each representation and rung, ε_Q := max of Δ_Q over the 24 pooled within-arm pilot pairs (8 per arm, N = 150k). Written by `src/gates.py` to `prereg/eps_S2_1.json` (hash in STATUS). Secondary: ε at the pooled pilot 0.9-quantile; full p̂_Q(ε) curves always reported.
- A run whose training diverged or whose S features are non-finite fails every rung in every pair it belongs to.

### 2.5 Decisions
Per (pair set, rung): x = #pairs with Δ_Q ≤ ε_Q, n = #pairs; one-sided 95% Clopper–Pearson: **reliable** if the lower bound > 0.9, **unreliable** if the upper bound < 0.8, else inconclusive (n = 32: reliable iff 32/32, unreliable iff ≤ 21; n = 64: ≥ 62 / ≤ 45; n = 96: ≥ 92 / ≤ 69). Ceiling for a cross pair set (X,Y): c_Q = √(p̂_Q(XX)·p̂_Q(YY)). N_max = 500k.

Confirm (all on z-l2):
- **(i) ordinal near ceiling and improving.** For each T ∈ {T_N(10), T_O, T_E, MST}: c_T − p̂_T(A,B) ≤ 0.1 at N_max, and mean Δ_T(A,B) at 500k < at 50k (one-sided bootstrap over disjoint pairs, 2,000 resamples per cell, Holm over the 4 rungs at α = 0.05).
- **(ii) geometric obstruction.** For Q ∈ {Gs, Aff, SOG-τ0.1}: cross A–B **unreliable** at both N. Counts as evidence for the link only if within-arm p̂_Q ≥ 0.8 for both A and B at N_max; otherwise Q is "inconclusive (K3)".
- **(iii) isotonic quotient removes the gap.** mean Δ_iso(A,B) ≤ 1.5 × mean Δ_iso over the pooled within-A and within-B pairs, at N_max.
- **(iv) warp share.** median ω over cross A–B pairs ≥ 0.5, and median ω over within-A and over within-B pairs each ≤ 0.2, at N_max.
- **(v) matched control.** For Q ∈ {Gs, CKA, SOG-τ0.1}: p̂_Q(A,A_τ) ≥ c_Q(A,A_τ) − 0.1 at N_max; and raw G: A–A_τ unreliable while within-A and within-A_τ raw-G p̂ ≥ 0.8.
- Verdict: **link confirmed** if (i)–(v) all hold with no K3 item; **falsified** if median ω(A,B) < 0.2 or any ordinal gap c_T − p̂_T(A,B) > 0.1 at N_max; otherwise **partial**, listing each item. If any (ii) item is K3, the verdict on (ii) is "inconclusive (K3)".
- CKA is reported as mean(1−CKA) cross minus within with a bootstrap CI, not as reliable/unreliable (except inside (v)).

Secondary (not confirmatory):
- **Sharp link (speculative).** Per cross pair, β̂ = argmin_β Σ_{i<j}(K_B,ij − exp(β(K_A,ij − 1)))² on cosine Grams (bounded search, log β ∈ [log 0.01, log 100]). Prediction: median β̂(A,B) ∈ [2.5, 10] (within ×2 of 1/τ = 5) and median β̂(A,B)/median β̂(A_τ,B) ∈ [1.5, 3.5] (predicted 2.5).
- **Lemma 6 (co-occurrence).** Within-arm pairs; d̃ = d/Q_0.9(d) per model; near set = pairs in the lowest 1% of (d̃_A + d̃_B)/2, far set = upper 50%; e_set = RMS of log(d̃_A/d̃_B) over the set. R_set = mean e_set(50k)/mean e_set(500k). Prediction: R_near > R_far in arms A and A_τ, and log(R_near/R_far) larger for A (τ = 0.2) than A_τ (τ = 0.5). Bootstrap CIs (pairs resampled within cell).
- All-pairs U-statistics (all within-arm pairs, all cross pairs) for s_N(10), Gs_rms, CKA, RSA with run-level bootstrap CIs.
- Nulls: permutation (hrhv2 `calibrate`, K = 200) for s_N(10) and CKA on the first 4 pairs of each pair set; random-init null (z_init/h_init pairs); within-condition ceiling.
- Diagnostics: row-isotonic share, k-occurrence skewness (hubness; N_10 counts), z norms; covariates (train loss, gen gap, kNN accuracy) per arm × N; fixed-epoch cell profile.

## 3. S2.2 — gauge net

### 3.1 Training
- airbench94 trunk as above → h ∈ ℝ²⁵⁶; bias-free head **P: 256→9 (u = P h), W: 9×9 (y = W u)**, fixed orthonormal E (10×9, Helmert basis of 1⊥), logits = E y / 9. airbench94 recipe: batch 1024, lr 11.5 and weight decay 0.0153 per 1024 examples (decoupled form), Nesterov momentum 0.85, BN-bias lr ×64, label smoothing 0.2, warm-up 23% then linear decay to 0.07, flip + 2-px reflect translate, whitening bias trained for the first 30% of steps, bf16 autocast, no TTA.
- **Budget 500,000 images seen** (488 steps; ≈ airbench94's default 9.9 epochs of 50k) at both N.
- Arms: **noWD** (no weight decay on P, W; backbone keeps WD), **WD** (weight decay on P, W), **smallinit** (noWD, P and W default init × 0.1).
- **N ∈ {25,000, 250,000}; 192 runs per (arm, N)** = 1,152 runs; plus the **shared-corpus cell** noWD at 25k: 4 corpora × 48 runs = 192 runs.
- Saved on S: y (9), u (9), h (256), their values at init, P, W; accuracy on S/bank/own-train, CE train vs hold (gen gap), relative imbalance ρ = ‖WᵀW − PPᵀ‖_F/(‖WᵀW‖_F + ‖PPᵀ‖_F) at init, every 50 steps and at the end.
- Pre-pilot engineering (excluded): ρ_end ≈ 0.28–0.30 noWD, 0.03–0.04 WD, and 0.24–0.29 for smallinit (SGD with momentum and a finite lr does not conserve WᵀW − PPᵀ). The smallinit arm's "balanced" premise is therefore not expected to hold; the arm is kept, and P5 below tests whether small initialisation alone suffices under SGD.

### 3.2 Gate G1 (imbalance; pilot EXCLUDED; exp `S2.2-pilot`)
16 runs per arm at **N_pilot = 100,000**. Pass if median ρ_end ≥ 0.2 for noWD and ≤ 0.05 for WD. Evaluated automatically by `src/gates.py` (`runs/GATE_S2_2_main.go|.nogo`). If it fails: add an unbalanced-init arm before freezing (deviation recorded).

### 3.3 Pairs, criteria, tolerance
- Disjoint within-cell pairs (rep 2j, 2j+1): 96 per (arm, N); shared corpus: (2j, 2j+1) within each corpus, 24 × 4 = 96 pairs.
- Representations y, u, h with pre = `none` (primary); h with `l2` (secondary). Full ladder on every pair; GL criterion Δ_Π = projector distance (`gl_projector_dist`).
- Rungs: T_N(10) and Gs (primary), plus 1 − CKA, Δ_O, Δ_E, 1 − s_T, 1 − RSA, 1 − SOG-τ0.1, Δ_Π.
- **Function-anchored tolerance**: ε_T(y) := max of Δ_T(y, y') over the 24 pooled within-arm pilot pairs (8 per arm, N = 100k); **ε_T(u) := ε_T(y)**; ε_Π := max pilot Δ_Π(y, y'); ε_T(h) := max pilot Δ_T(h, h') (secondary). Written by `src/gates.py` to `prereg/eps_S2_2.json` before any main ladder.
- Sanity: Π_u = Π_y (projector distance between u and y of the same run ≤ 1e-6) on every run with cond(W) < 1e6.

### 3.4 Predictions (CP decisions as in §2.5)
- **P1** noWD: u **unreliable** at both N for T_N(10) and Gs.
- **P2** noWD: y **reliable** for T_N(10) and Gs, and Δ_Π reliable, at N = 250k (25k reported).
- **P3** WD and smallinit: u **reliable** for T_N(10) and Gs at N = 250k.
- **P4** gauge localization: |mean s_N(10)(h) between any two arms| < 0.05 at each N.
- **P5** |p̂_Q(u, smallinit) − p̂_Q(u, WD)| ≤ 0.1 for T_N(10) and Gs at both N.
- **Falsifier**: noWD u reliable (T_N(10) or Gs) at either N → "SGD selects a common gauge"; v2's GL paragraph then states this training rule does not realise the obstruction.
- **μ_r vs μ_r(·|C)**: shared-corpus noWD 25k vs independent noWD 25k: p̂ for u, y, h and mean Δ, bootstrap differences; expectation (not confirmatory): u stays unreliable under a shared corpus.

## 4. Statistics, partial completion, reporting
- Bootstrap: 2,000 resamples of the disjoint pairs within each pair set (disjoint pairs are i.i.d.); different cells are resampled independently. All-pairs U-statistics use a run-level bootstrap (runs resampled within arm).
- Holm across the primary endpoints where p-values exist ((i) improvement tests).
- **Partial completion**: if main runs are incomplete at an analysis, the analysis uses reps 0…R−1 with R the largest even number such that every cell of that experiment has all those reps done (the rep-major queue makes this a prefix); such analyses are labelled INTERIM. The final analysis uses all targeted runs. Failed runs are re-queued; diverged runs are kept and count as failing.
- Every table reports n, x, p̂, CP bounds, decision, ε, and the p̂(ε) curve.

## 5. Deviations from final_plan_en.md (all decided before main runs)
1. Spectral arm uses HaoChen's ball projection μ = 1 (unconstrained loss diverged in excluded engineering runs); B is effectively sphere-constrained.
2. Pilot conditions: S2.1 at N = 150k, S2.2 at N = 100k (disjoint from tested cells); ε rule = max over pooled within-arm pilot pairs.
3. S2.2 budget fixed at 500k images seen at both N (the plan does not specify the budget).
4. Shared-corpus cell uses the noWD arm (the plan does not name the arm).
5. Nulls: permutation nulls on a subset of pairs (first 4 per set), K = 200.
6. GPU is shared with another role; ETA and completion are reported, not assumed.
